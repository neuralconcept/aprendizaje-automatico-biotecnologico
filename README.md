# Animaciones del curso «Aprendizaje automático (Machine Learning) en el sector biotecnológico»

Universidad San Jorge. Este repositorio aloja las animaciones que acompañan a las presentaciones del curso, para poder enlazarlas desde los PDF.

- Página con todas las animaciones: https://neuralconcept.github.io/aprendizaje-automatico-biotecnologico/
- Cada vídeo tiene su enlace directo: `https://neuralconcept.github.io/aprendizaje-automatico-biotecnologico/videos/<unidad>/<fichero>.mp4`

Contiene 62 animaciones cortas (20–35 s) organizadas por unidad en `videos/`.

Autor: Rafael del Hoyo Alonso.
